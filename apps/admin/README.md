# @jjoin/admin

JJOIN HQ Admin (Vite + React).

## Run

```bash
pnpm --filter @jjoin/api start:dev
pnpm --filter @jjoin/admin dev
```

Open http://localhost:5173 — login with **DEV_ADMIN** (mock/hybrid).

## Docs

See [docs/admin/README.md](../../docs/admin/README.md).

## Scripts

- `dev` — Vite
- `build` / `typecheck` — production build gate
- `preview` — preview dist
